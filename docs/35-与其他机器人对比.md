# 35 · 与其他四类机器人的区别（专业版）

> 这篇给要跑分/做技术对比的人看。口语版见 [一分钟看懂.md](../一分钟看懂.md)。
> 说明：以下对比的是**四类形态**，不是点名某个产品；具体版本的跑分请在独立会话里用同一套题跑。

---

## 一、对比对象：四类形态

| 代号 | 形态 | 典型代表思路 |
|---|---|---|
| **A** | 插件式 IM 机器人框架（OneBot/NapCat 生态） | 事件路由 + 插件市场，功能靠堆插件 |
| **B** | 角色卡 / 角色扮演前端 | 人设写在卡里，上下文塞提示词，靠前端管理会话 |
| **C** | Agent / 工作流平台 | 节点编排 + 工具调用，强在任务完成 |
| **D** | RAG 知识库问答 | 文档切块 + 向量检索，强在知识准确 |

SymBot 不属于这四类的任何一类，它是**单机常驻的"数字生命"运行时**：记忆、关系、人格、作息、主动开口是一套账，通道和工具是外挂。

## 二、能力矩阵

| 维度 | A 插件框架 | B 角色卡 | C Agent 平台 | D RAG 问答 | **SymBot** |

## 三、跑分建议（给独立对比会话用）

要横向比，别比"谁功能多"，比**同一件事在时间维度上的表现**。建议四组题：

### 1. 记忆一致性（7 天）
- 第 1 天说 20 条事实（含 3 条矛盾项）
- 第 3、5、7 天各问 10 条
- 指标：**召回率 / 矛盾处理 / 过时信息是否还在**

### 2. 关系连续性
- 连续 5 天同一话题推进关系，中间穿插 1 次冲突、1 次道歉
- 指标：**阶段是否单调合理 / 冲突后是否回退 / 恋人唯一性**

### 3. 主动性
- 静置 12 小时，记录主动开口次数与时机
- 指标：**夜间是否闭嘴 / 配额是否守住 / 开口是否有据（能不能说出依据）**

### 4. 迁移性
- 把 `data/` 拷到另一台机器（或换模型），继续同一段对话
- 指标：**人设漂移度 / 记忆保留率 / 关系数值是否保持**

> SymBot 的基线数字：adv_regress 35/35、smoke 387/0、fullcheck 149/149 + 路由 129/129、panel_check 145/0；
> 这些是**自测**，不是横向跑分，别混着用。

## 四、我们的取舍（写给评审）

1. **不做插件市场**：模块只做"够用的扩展点"，避免变成又一个框架；
2. **不做多机**：单进程单例，记忆是一个 SQLite 文件，换来的是一致性和可迁移；
3. **记忆闭源**：核心算法不公开，只给接口和加密运行时；
4. **不做群管**：群聊只做语境、印象、迎新，不做踢人/禁言/风控；
5. **优先"像人"而不是"能干活"**：工具是顺手，不是主业。
