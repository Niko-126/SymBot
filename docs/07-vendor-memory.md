# 07 · 记忆引擎（闭源运行时）

> 只讲边界与接口，不描述实现。

## 1. 是什么

Symvolve Memory 的**衡忆精简严格版**：模型无关、多用户、单机本地存储的记忆引擎，
以加密封装（`app/memory/_vault.bin`）随程序分发，对外只经 `app/memory/api.py` 暴露能力。

## 2. 能力

| 能力 | 说明 |
|---|---|
| 写入 | 记忆条目落库，按用户与场合分区 |
| 召回 | 按线索找回，返回可解释结果（置信度、命中原因） |
| 衰减 | 常用回升、久不用变淡（策略由引擎内部决定） |
| 钉住 | 重要记忆不参与遗忘 |
| 遗忘 | 单条删除 / 按用户清空 |
| 统计 | 条数、类型分布 |
| 迁移 | 整库导出导入（`data/` 即全部） |

## 3. 分发与为什么没有实现文档

引擎已独立立项（Symvolve Memory），实现属闭源资产：源码不在仓库、不在安装包、不在文档里。
**本文不提供**表结构、算法、参数、模块划分。评估请按 [docs/35](35-与其他机器人对比.md) 的能力矩阵，
从外部行为打分。
