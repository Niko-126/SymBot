# 07 · 记忆引擎（闭源运行时）

> 本文只说明**边界与接口**，不描述实现。引擎内部实现不在本仓库、也不在本文档范围内。

## 1. 它是什么

Symvolve Memory 的**衡忆精简严格版**：一个模型无关、多用户、单机本地存储的记忆引擎，
以加密封装（`app/memory/_vault.bin`）随程序分发，对外只通过 `app/memory/api.py` 暴露能力。

## 2. 对外能力

| 能力 | 说明 |
|---|---|
| 写入 | 一条记忆（事件/事实/偏好/念头等）落库，按用户与场合分区 |
| 召回 | 按线索找回相关记忆，返回可解释的结果（命中原因、置信度） |
| 衰减 | 常用回升、久不用变淡（由引擎内部策略决定） |
| 钉住 | 重要记忆不参与遗忘 |
| 遗忘 | 单条删除、按用户清空 |
| 统计 | 条数、类型分布、活跃度 |
| 迁移 | 整库导出/导入（`data/` 目录即全部） |

## 3. 分发方式

- 发布版只带**加密容器** + 解封器 + 接口层，运行期解到临时目录，进程退出即擦除；
- 容器与机器绑定，换机需重新打包或用口令模式（见 `docs/36`）；
- 源码不在仓库、不在安装包、不在任何文档里。

## 4. 为什么没有实现文档

这套引擎已独立立项（Symvolve Memory），实现细节属于闭源资产。
**本文档不提供**：表结构、算法、参数、权重、迁移脚本、模块划分。
需要评估请按 `docs/35` 的能力矩阵与 `docs/评测/` 的评测标准，从外部行为打分。
