# 36 · 记忆系统说明（衡忆 / Symvolve Memory）

> 本文只讲**能力与边界**，不描述实现。衡忆记忆内核闭源，原因见第二节。

## 一、它是什么

她有一套自己的记忆，不是把聊天记录一股脑塞回给模型：

- **长期记住**：你说过的事、你的习惯、你们之间的梗，会留下来
- **按人分区**：同一个群里，A 的记忆不会串到 B 头上
- **会淡忘**：常提起的记得牢，很久不提的会慢慢变淡（不是突然消失）
- **可钉住**：重要的可以钉住，钉住的不参与遗忘
- **可编辑、可删除**：面板里能看、能删；删了就真没了
- **可导出、可迁移**：数据在 `data/` 里，整个目录拷走就是搬家

## 二、为什么闭源

衡忆记忆内核已经**独立立项**为 **Symvolve Memory**，方向是通用的向量化记忆系统，
和"数字生命"这条产品线的诉求不一样，所以不便开源。
你现在用到的这套，是 **Symvolve Memory 的"衡忆精简严格版"**——能力收敛、边界更硬，
专门为"一个具体的人"服务。

> 本文不写实现细节，也不提供逆向线索；想看能力对比，见 [docs/35](35-与其他机器人对比.md)。

## 三、⚠️ 请自己备份（重要）

内核**不开源**，所以：

- 不要手改 `data/life.db`、不要用别的工具往库里写；
- 升级、搬家、重装前，**先把整个 `data/` 复制一份**（含 `life.db-wal`、`life.db-shm`）；
- 误操作（删库、覆盖、换机没带 `data/`）导致的数据损坏，作者**无法保证**能修。

**备份怎么做**：关掉程序 → 复制 `data/` 到别处 → 再动程序。
运行中直接拷 `life.db` 可能拿到旧快照（SQLite WAL），要连 `-wal`、`-shm` 一起。

## 四、数据坏了怎么办

发邮件到 **mendastudio@163.com**，标题写「复活小鱼」，附上：

1. `data/` 的备份（或 `life.db` + 两个 wal 文件）；
2. 大概什么时候、做了什么操作；
3. 你希望恢复到什么状态（最近一次、某天、还是只要能打开）。

作者会尽力把"你的小鱼"捞回来；能恢复到哪一步取决于备份完整度，不保证 100%。

## 五、和 SMD-P 的关系

**SMD-P 是 SymBot 的前身**。项目改名后，代码、协议、数据格式一脉相承；
老版本的 `data/` 可以直接放进新版的 `data/` 继续用（升级前照第三节备份）。
