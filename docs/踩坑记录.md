# 踩坑记录

> 都是真机上踩出来的，不是推演。改代码、打包、发版之前扫一眼，能省半天。

## 网络和代理

**系统代理指到一个死端口，本地请求也会挂。**
httpx 默认 `trust_env=True`，会去读 Windows 系统代理。Clash 退了，注册表里的代理还留着，结果连 `127.0.0.1:3000` 都被塞进死代理。
规矩就一条：所有打本地服务的 httpx 客户端一律 `trust_env=False`（onebot / console._qq_send / group / announce / veto）。

**pip 被同一个代理卡住。**
加两个参数绕过去：`pip install --proxy "" --index-url https://pypi.org/simple`。

**PowerShell 调试也走系统代理。**
`Invoke-WebRequest` 一样读代理设置，调试时加 `-NoProxy`。

## 进程和窗口

**`DETACHED_PROCESS` 下跑 `powershell.exe`，rc=0 秒退，脚本一行都没执行。**
要"父进程死了子进程还活着"，用 `CREATE_NO_WINDOW | CREATE_NEW_PROCESS_GROUP`。实测父进程被杀之后它还在。

**PyInstaller `--noconsole` 下 `sys.stdout` / `sys.stderr` 是 `None`。**
库里随便一个 `print` 直接炸。入口第一件事：`if sys.stdout is None: sys.stdout = open(os.devnull,'w')`。

**Electron 打包后 `process.resourcesPath` 指到 `<app>/resources`。**
你在 `extraResources` 里写 `resources/kernel`，最后会变成 `<app>/resources/resources/kernel`。多套一层，就找不着文件。

**数据目录别拼两层。**
配置里的 `db_path` 已经带了 `data/` 前缀。数据根要指到 exe 所在目录，别指到 `data/`。

**本机 shell 可能带着 `ELECTRON_RUN_AS_NODE=1`。**
测 Electron 之前先 `Remove-Item Env:ELECTRON_RUN_AS_NODE`。不然 exe 当 Node 跑，秒退，日志里什么都没有。

## 打包

**electron-builder 的 `files` 白名单要带上 `splash.html`。**
漏了不报错，就是启动动画不显示。

**打包前确认 `desktop/resources/kernel/SymBotKernel.exe` 真在。**
漏了安装包会小 30 MB，装完起不来。打完对一下体积：Core 约 106 MB，Standard 约 191 MB。

**npm 的 `version` 必须是 semver。**
`0.2-P` 不合法。Electron 内部写 `0.2.0`，对外文件名再写 `0.2-P`。

**NSIS 单文件上限大约 2 GB。**
Full 包 9.3 GB，打不成一个 exe。要么分卷，要么拆成"程序安装器 + 资源包"。

## GitHub 发布

**中文资产名上传会截断或乱码。**
中文 bat 传上去，名字变成 `default.bat`。资产一律用 ASCII 名。

**删 tag 会让 Release 变回草稿。**
重建同名 tag 之后，还得重新 `PATCH draft=false`。

**提交作者邮箱会公开。**
发布前统一改掉（`filter-branch --env-filter`，或者干脆 orphan 重建）。

**`git filter-branch` 有时候"看起来跑了"，refs 其实没动。**
最稳的是 orphan 单提交重建，干净、还能验证：`git rev-list --count` 等于 1。

**强推之前先 `git bundle create` 备份。**
这一步省下来的时间，出事的时候要拿几倍还回去。

## Windows 和 PowerShell

**Windows PowerShell 5.1 按 ANSI 读 .ps1。**
带中文的脚本必须存成 UTF-8 with BOM。不然报"字符串缺少终止符"，够你怀疑半天。

## 发布前扫一遍

**仓库根目录的 `life.db`、`config.local.yaml`、`data/` 不要入库。**
本机数据进了仓库，就跟着历史一起走了。

**`grep` 一遍再发。**
真实 QQ、群号、邮箱、本机路径、`sk-` 开头的 key，一个都别留。

**公开文档只写"怎么用、有什么边界"。**
内部怎么做的别往里写。写进去容易，改历史很贵。
