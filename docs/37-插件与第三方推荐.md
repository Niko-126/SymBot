## 1. 接 QQ：NapCat（推荐使用）

- 项目：<https://github.com/NapNeko/NapCatQQ>
- 用途：QQ NT 的 OneBot v11 注入端，SymBot 通过它收发 QQ 消息
- **推荐理由**：目前对 SymBot 兼容性最好（消息格式、文件上传、登录二维码都实测过）
- 注意：需要管理员权限；QQ 客户端版本要和 NapCat 对得上

> 装了记得去点 star：<https://github.com/NapNeko/NapCatQQ/stargazers>

## 2. 语音：本地 TTS 服务（可选）

SymBot 只对接 HTTP 契约（`POST /v1/speech` + `GET /v1/jobs/{id}`），**不绑定具体实现**。

- 参考实现：CosyVoice 系列（阿里开源）<https://github.com/FunAudioLLM/CosyVoice>
- 音色转换：RVC <https://github.com/RVC-Project/Retrieval-based-Voice-Conversion-WebUI>
- **推荐**：先跑通 CosyVoice 官方推理，再考虑换声；权重与许可以上游为准
- 没有 TTS 也能聊天，只是没有语音条

## 3. 翻唱 / 点歌（可选）

- 人声分离：Demucs <https://github.com/facebookresearch/demucs>
- 音频下载：yt-dlp <https://github.com/yt-dlp/yt-dlp>
- 混音转码：ffmpeg <https://ffmpeg.org/>
- **推荐**：先装 ffmpeg 并进 PATH，再装 demucs；yt-dlp 记得定期升级
