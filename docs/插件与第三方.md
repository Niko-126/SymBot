# 插件与第三方

> 这篇说清三件事：要额外装什么、那些东西是谁的、各是什么许可。
> 装之前先看一眼，省得装到一半卡住还不知道卡在哪。

## 一句话前提

仓库里只放我们自己的代码和文档。第三方组件、模型权重、素材，一样都不带。缺什么，你自己补。

## 接 QQ：要一个 OneBot 端

SymBot 不会自己去登 QQ。它只管连一个本地地址收发消息，协议是 OneBot v11。中间这一层，最省事的是 NapCat。

| 项 | 说明 |
|---|---|
| 干什么 | 把 QQ 的消息转成事件，再把回复转回去 |
| 哪儿下 | 它的 GitHub 仓库，<https://github.com/NapNeko/NapCatQQ> |
| 怎么装 | 照它自己的文档来，别照抄别人的教程 |
| 谁维护 | 第三方，跟我们不是一个项目 |
| 许可 | 以原仓库为准，用之前自己看一眼 |

三条规矩，装了就要守：

1. 只登你自己的号。别人的号，一律不碰。
2. 登录凭据、二维码截图，别往任何地方发。
3. 它更新了你就跟着更新。QQ 客户端版本对不上，登不上，这不是 SymBot 的问题。

还有一句：别拿它群发、别拿它骚扰人。号被封了，找谁都没用。

不接 QQ 也能用。面板里直接聊，功能一样全。

## 语音条：要一个本地 TTS 服务

SymBot 不绑具体实现，只认一套 HTTP 接口。你起什么服务都行，满足下面三条就能出声。

```text
POST {地址}/v1/speech
  {"text": "要说的话", "voice": "音色名", "style": "风格"}
  → {"id": "任务号", "status": "pending"}

GET {地址}/v1/jobs/{任务号}
  → {"status": "pending|running|success|failed|interrupted", "error": "出错时的说明"}

GET {地址}/v1/jobs/{任务号}/audio
  → WAV 音频
```

约定：

| 项 | 要求 |
|---|---|
| 地址 | 本机，默认 `http://127.0.0.1:9880`，设置页里能改 |
| 提交 | 一次一句话，三个字段：内容、音色、风格 |
| 查询 | 一秒半轮一次，直到成功或失败 |
| 音频 | 必须是 WAV，别的格式不收 |
| 开关 | 默认关。关着的时候，一个字节都不出网 |

模型权重不在仓库里，也不在安装包里。要哪个声音，你自己下、自己放。许可也跟着模型走，别拿别人的声音去商用。

没有 TTS 也能聊。只是发不出语音条，别的都在。

## 翻唱：三件套，全在本机跑

| 组件 | 干什么 | 许可 |
|---|---|---|
| demucs | 把歌拆成人声和伴奏 | MIT |
| RVC | 把人声换成目标音色 | MIT |
| yt-dlp | 下音频 | Unlicense |
| ffmpeg | 转码、切片、混音 | LGPL 或 GPL，看编译选项 |

顺序建议：先把 ffmpeg 装好、加进 PATH，再装 demucs，最后折腾 RVC。yt-dlp 隔段时间升一次，不升就下不动。

全部在本机跑，音频不上传。版权归原权利人：自己听可以，别拿去发布，更别拿去卖。

## 表情包：仓库里没有

源码仓库不带表情包。`data/stickers/` 是空的，得你自己攒。

- 放什么：png、jpg、gif、webp 都行，扔进目录，面板里就能选。
- 装哪个版本：Standard 安装包自带一套基础素材，Core 没有。
- 版权：你找来的图，版权归原作者。要发布、要商用，先确认授权。
- 最稳的做法：用自己画的、自己拍的，或者明确允许二次使用的。

## 一张总表

| 组件 | 干什么 | 谁维护 | 在不在仓库 | 许可 |
|---|---|---|---|---|
| NapCat | 接 QQ，转 OneBot v11 | 第三方 | 不在 | 以原仓库为准 |
| 本地 TTS 服务 | 把文字念出来 | 第三方 | 不在 | 看具体实现 |
| TTS 权重 | 决定声音像谁 | 第三方 | 不在 | 看具体模型 |
| demucs | 拆人声和伴奏 | 第三方 | 不在 | MIT |
| RVC | 换音色 | 第三方 | 不在 | MIT |
| yt-dlp | 下音频 | 第三方 | 不在 | Unlicense |
| ffmpeg | 转码混音 | 第三方 | 不在 | LGPL 或 GPL |
| 表情包 | 发表情 | 你自己 | 不在 | 归原作者 |

内核自己用的 Python 包都在 `requirements.txt` 里，一条命令装完，不算第三方插件。

## 本仓库不含任何第三方权重和二进制

这条最容易误会，再说一遍：

- 没有 TTS 权重，没有换声模型，没有声音素材。
- 没有 QQ 客户端，没有 OneBot 端，没有 ffmpeg。
- 没有表情包图库。

安装包里只有我们自己的东西。第三方缺了，对应功能会标「未配置」，程序不会崩，别的功能照常用。
