## 想让它在 QQ 里说话 → NapCat

- 项目：<https://github.com/NapNeko/NapCatQQ>
- 干什么：QQ NT 的 OneBot v11 注入端。SymBot 靠它收发 QQ 消息。
- 为什么推它：目前兼容性最好。消息格式、文件上传、登录二维码都实测过。
- 提醒：要管理员权限。QQ 客户端的版本得和 NapCat 对上，对不上就登不上。

点星走这儿：<https://github.com/NapNeko/NapCatQQ/stargazers>

## 想要语音条 → 本地 TTS

SymBot 只认 HTTP 契约，不绑具体实现：

```
POST /v1/speech
GET  /v1/jobs/{id}
```

只要你能起一个满足这两条的服务，谁来都行。

- 参考实现：CosyVoice 系列（阿里开源）<https://github.com/FunAudioLLM/CosyVoice>
- 音色转换：RVC <https://github.com/RVC-Project/Retrieval-based-Voice-Conversion-WebUI>
- 建议顺序：先把 CosyVoice 官方推理跑通，再折腾换声。权重和许可都以上游为准。
- 没 TTS 也能聊天，只是没有语音条。

## 想让它翻唱、点歌

- 人声分离：Demucs <https://github.com/facebookresearch/demucs>
- 音频下载：yt-dlp <https://github.com/yt-dlp/yt-dlp>
- 混音转码：ffmpeg <https://ffmpeg.org/>
- 建议顺序：先装 ffmpeg 并塞进 PATH，再装 demucs。yt-dlp 记得隔段时间升一次，不升就下不动。

## 跑起来要的 pip 包

`requirements.txt` 里的，`pip install -r requirements.txt` 一把装完。

| 包 | 干什么 | 项目 |
|---|---|---|
| fastapi / uvicorn | HTTP 框架 + ASGI 服务器 | <https://github.com/fastapi/fastapi> |
| httpx | 出站 HTTP | <https://github.com/encode/httpx> |
| pydantic | 数据校验 | <https://github.com/pydantic/pydantic> |
| PyYAML | 读配置 | <https://github.com/yaml/pyyaml> |
| tzdata | 时区 | <https://github.com/python/tzdata> |
