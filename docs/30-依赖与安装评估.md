# 30 · 依赖与安装难度评估

> 目的：说清楚"装起来有多难、难在哪、哪些是作者自研、哪些要用户自己下"。
> 写于 2026-11-02。数字都是真机实测（RTX 3080 / Win11 / Python 3.11 venv）。

---

## 一、一句话结论

| 用户类型 | 要装什么 | 难度 | 耗时 |
|---|---|---|---|
| **只想聊天**（不要语音/不要翻唱） | Python 环境 + `pip install -r requirements.txt` + NapCat + 一个 LLM api_key | ★★☆☆☆ | 15–25 分钟 |
| **要语音条**（TTS） | 上面 + 肥鱼 CosyVoice3 服务（权重 7.1 GB）+ CUDA 环境 | ★★★★★ | 2–5 小时（下载为主） |
| **要翻唱**（换声） | 上面 + demucs + RVC + ffmpeg | ★★★★☆ | 1–2 小时 |
| **只要面板/试玩** | Python + `pip install` + 一个 key（无 QQ 也能用面板） | ★☆☆☆☆ | 5 分钟 |

**最难的从来不是本项目**，是三个外部件：NapCat（要被 QQ 环境接受）、CosyVoice3 权重（体积+驱动）、RVC（同上）。
所以仓库**不打包**这三样，改成"接口 + 引导"。

## 三、安装难度分解（逐项评分）

评分：★=1 分（越难分越高）

| 环节 | 难度 | 卡点 | 可缓解手段 |
|---|---|---|---|
| Python 3.11 venv | ★ | 版本别用 3.14（部分包没轮子） | 提供 `install.ps1` 自动装 uv + 3.11 |
| `pip install -r requirements.txt` | ★ | 国内网络慢 | 给清华/阿里镜像一键切换 |
| 填 api_key | ★ | 不知道填哪 | 面板「设置 → 连接 → 模型 API Key」保存（只写 `config.local.yaml`，不进仓库） |
| NapCat 装 + 登录 | ★★★★ | 需管理员、要 QQ 客户端版本匹配、常被风控 | 面板内「服务控制」+ 二维码/快速登录（P0 待办） |
| NapCat 上报地址 | ★★★ | 默认 8788，本项目要 8787 | 首次启动自动改配置并备份 `.bak` |
| CosyVoice3 服务 | ★★★★★ | 7.1 GB 权重 + CUDA 12.8 + Python 3.11 专用环境 | 只给"接口 + 检测"，面板显示未装并给下载指引 |
| demucs | ★★★ | torch 体积大、TorchCodec 报错 | 文档给绕过写法（soundfile + apply_model） |
| RVC | ★★★★ | 权重 + 索引 + 掉电平 | 文档给自动补电平（+7.3 dB 实测值） |
| ffmpeg | ★★ | 要进 PATH | `install.ps1` 检查并提示 winget 命令 |

## 四、最小可用安装（15 分钟路径）

```powershell
git clone <repo> SymBot; cd SymBot
py -3.11 -m venv .venv; .\.venv\Scripts\activate
pip install -r requirements.txt
copy config.example.yaml config.local.yaml
# 只填 provider.api_key（其余留空即可用面板）
python -m app.cli serve --port 8787
# 浏览器打开 http://127.0.0.1:8787
```

**不带 QQ、不带语音**也能完整体验：面板聊天、记忆、关系、日程、热梗。

---

## 五、接 QQ（+10 分钟，不含 NapCat 自身折腾）

1. 装 NapCat（用户自理）；
2. 面板「设置 → 连接与账号」填 NapCat 目录与小号 QQ → 服务控制一键启动；
3. 确认上报地址改成 `http://127.0.0.1:8787/onebot/event`（面板会自动改并备份）；
4. QQ 里给她发一句话 → 面板「控制台」应能看到事件。

---

## 六、接语音（可选，最重的一块）

**本项目只提供接口，不提供权重。** 面板显示：

```
语音服务：未连接
  → 需要本地 CosyVoice3 兼容服务（默认 http://127.0.0.1:9880）
  → 模型不随本项目分发，请自行获取并遵守其许可
  [ 检测连接 ]  [ 查看接入说明 ]
```

接入成功后面板显示：模型名、CUDA 状态、上次合成耗时、日志尾 200 行。
TTS 进程用 `CREATE_NO_WINDOW` 起，**不弹黑框**，输出重定向到 `data/voice_service.log`。
