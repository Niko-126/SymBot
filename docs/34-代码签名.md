# 34 · 代码签名（Windows exe）

> 目的：让用户双击 Release 里的 exe 时不看到「未知发布者」，并让 SmartScreen 不拦。
> 这份文档只讲**事实与操作**，不替你做采购决定。

---

## 一、先搞清楚三件事

1. **自签名证书没用**：只能在你自己的机器上被信任，别人下载照样红屏。
2. **2023 年 6 月起，CA/B 规则要求 OV/EV 代码签名私钥必须放在硬件令牌或 HSM 里**，
   不再给你一个可以随便拷的 `.pfx`。所以「买个证书文件」这条路已经没有了。
3. **SmartScreen 看两样东西**：证书类型（EV 通常即时建立信誉）＋ 下载量/时间（OV 需要累积）。

---

## 二、几条真实可选的路

| 路线 | 大概价格 | 需要什么 | SmartScreen | 适合 |
|---|---|---|---|---|
| **OV 代码签名证书**（硬件令牌） | ¥1200–2500 / 年 | 个人实名或企业营业执照 | 需累积下载量，前期仍可能拦 | 长期自用、预算有限 |
| **EV 代码签名证书**（硬件令牌/HSM） | ¥2500–4500 / 年 | 企业主体（多数 CA 不接受个人） | 通常即时可信 | 有公司主体、要立刻干净 |
| **Azure Trusted Signing** | $9.99 / 月 | Azure 订阅 + 组织验证（一般要求 3 年经营历史） | 与普通 OV 类似 | 有 Azure、有公司 |
| **Microsoft Store（MSIX）** | $19 一次性（个人开发者） | 微软开发者账号 | 商店分发**绕开** SmartScreen | 不想买证书 |
| **不签名** | 0 | — | 每次红屏，需点「仍要运行」 | 小范围内测 |

> 我们的许可 **不是 OSI 开源**（source-available），所以 SignPath / Certum 的开源免费签名基本不适用。

---

## 三、拿到证书之后怎么签（本仓库已备好脚本）

```powershell
# 1) 证书装在「当前用户\个人」里（CA 的安装向导会做），先看指纹
Get-ChildItem Cert:\CurrentUser\My -CodeSigningCert | Format-Table Subject, Thumbprint, NotAfter

# 2) 签名 + 时间戳 + 校验 + 重算 SHA256SUMS
.\scripts\sign_release.ps1 -Thumbprint <证书指纹>

# 3) 只检查环境、不真签
.\scripts\sign_release.ps1 -WhatIf
```

脚本做的事：

1. 取 `Releases\v<版本>` 下所有 `.exe`；
2. 用 `Set-AuthenticodeSignature`（系统自带，不依赖 Windows SDK）签 SHA256；
3. 打 RFC3161 时间戳（默认 DigiCert，可 `-Timestamp` 换）；
4. 逐个校验 `Status = Valid`；
5. **重新生成 `SHA256SUMS.txt`**——签名会改文件哈希，旧的校验值全部作废。

> 如果需要 `signtool`（某些 CA 的令牌驱动要求），装 Windows SDK 后加 `-UseSignTool` 即可。

---

## 四、没有证书时怎么办（当前状态）

Release 说明里写清楚：

- 提供 `SHA256SUMS.txt`，让用户自己核对；
- 说明「首次运行可能提示未知发布者，点『更多信息 → 仍要运行』」；
- 不要教用户关 SmartScreen / 关杀软。

这不是长久方案，但比让用户下载一个来源不明的 exe 强。

---

## 五、签完要检查什么

```powershell
Get-AuthenticodeSignature .\Releases\v0.1.0\SymBot-Core.exe | Format-List Status, StatusMessage, SignerCertificate
```

- `Status = Valid` 且 `SignerCertificate.Subject` 是你的主体名；
- 双击 exe 属性 → 「数字签名」页能看到签名与时间戳；
- 换一台**没装过证书**的机器下载，确认不再提示未知发布者（SmartScreen 仍可能按信誉拦，属正常）。

---

## 六、当前选择：自签名（A）+ 校验兜底（D）

2026-11-03 决定：先用**自签名证书**把 exe 签上，同时用 SHA256 兜底，等有量/有预算再买 CA 证书。

- 证书：`CN=SymBot Project (Self-Signed), O=Jingheng Wanxiang / Symvolve, C=CN`，RSA 3072 / SHA256，3 年
- 公钥：`Releases/v0.1.0/certs/SymBot-SelfSigned.cer`（私钥只在作者机器 `Cert:\CurrentUser\My`）
- 用户侧：双击 `信任证书.bat` → 根证书 + 受信任发布者 → 不再提示未知发布者；不装也能点「仍要运行」
- 校验：`SHA256SUMS.txt` 每个文件一行，签名后重新生成

### 为什么自签名不是长久方案

陌生人没有理由信任你的根证书；它解决的是"文件被篡改"和"作者可验证"，**不解决 SmartScreen 信誉**。
真正的公众分发仍要 CA 证书（OV/EV）或走 Microsoft Store（商店代签名）。

### 免费开源签名的门槛（已核对）

- **SignPath Foundation**：要求 OSI 开源许可、无闭源组件、公开仓库 —— 本项目是 source-available + 闭源记忆，不符合。
- **Certum 开源证书**：要求 GitHub 项目 ≥1k star 且已有 Release、申请人中国国籍 —— 当前 0 star，暂不符合；
  可以先把项目发出去攒 star，达到门槛再申请。
