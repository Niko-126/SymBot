# 自己写模块

> 一句话：丢个目录进 `modules/`，重启（或者点「重新加载」），工具和路由就位。内核一行都不用改。
> 目录里没有 `manifest.json` 的文件夹，内核当没看见，不会崩。

## 三步

1. **建目录**：`modules/<id>/`。`<id>` 必须和 manifest 里的 `id` 一模一样，只许小写字母、数字、连字符。
2. **写文件**：`manifest.json` 加一个入口 `.py`。入口里必须有 `def register(api)`。
3. **生效**：重启内核，或者在面板「模块」页点「重新加载」。

## 目录长什么样

```
modules/
├── README.md              ← 内核第一次启动自动生成
├── hello/                 ← 示例模块，一个工具 + 一个路由，照着抄
│   ├── manifest.json
│   └── hello.py
└── <id>/
    ├── manifest.json
    ├── main.py            ← entry 指向它
    └── …（模板、数据、子脚本都放这一层）
```

**最常见的一种放错**：压缩包多套了一层，变成 `modules/x/hello/manifest.json`。
必须让 `modules/<id>/manifest.json` 直接躺在那儿。

模块目录不跟着数据目录走。模块是代码，不是数据，换个数据根不该让模块消失。

## manifest.json 六个字段

| 字段 | 必填 | 怎么填 |
|---|---|---|
| `id` | 是 | 模块 id，小写字母、数字、连字符。**必须等于目录名** |
| `name` | 是 | 面板上显示的名字，中文随便写 |
| `version` | 是 | 版本号，`1.0.0` 这种 |
| `entry` | 是 | 入口 `.py` 的相对路径，相对模块目录，不许用 `..` 跳出去 |
| `kind` | 是 | `tool` / `route` / `hook` / `mixed` |
| `requires` | 是 | pip 包名列表。只校验，不代装。没依赖就写 `[]` |

照抄这个：

```json
{
  "id": "hello",
  "name": "示例模块 · 你好",
  "version": "1.0.0",
  "entry": "hello.py",
  "kind": "mixed",
  "requires": []
}
```

填错会报什么，原文在这儿：

| 字段 | 报错原文 |
|---|---|
| `id` | ``id 不合法：`Hello`（只能小写字母、数字和连字符，例：hello-world）`` |
| `id` | ``id `hello` 与目录名 `Hello-1` 不一致（目录名必须是模块 id）`` |
| `name` | ``name 必须是非空字符串`` |
| `version` | ``version 必须是非空字符串（例：1.0.0）`` |
| `kind` | ``kind 只能是 tool / route / hook / mixed，现在是 `x` `` |
| `entry` | ``entry 不许往上跳：`../../evil.py`（只能指向模块目录里的文件）`` |
| `entry` | ``entry 文件不存在：`main.py` `` |
| `requires` | ``缺依赖：requests（pip install requests；内核不自动装）`` |

还有些细节，知道一下能少踩坑：

- `manifest.json` 用 `utf-8-sig` 读，记事本存的 BOM 也认。
- `entry` 里的 `\` 会先归一成 `/`，Windows 上手写反斜杠不至于报错。
- 没有 `manifest.json` 的文件夹直接跳过；`.` 和 `_` 开头的目录也跳过。`__pycache__` 和半成品空目录不会刷屏。
- 同时错好几个字段时，面板只拼前 4 条，后面用 `…` 省略。
- `author`、`description`、`homepage` 这类额外字段随便写，不校验。
- `kind` 只是声明，用来分类和给你自己看的，不强制拦。`tool` 模块顺带挂个路由也能跑。
- `requires` 查依赖走两条路：先按发行名查，再按 import 名查。所以 `PyYAML` 和 `yaml` 两种写法都认。

## 入口里写什么

只要一个 `register(api)`。其他什么都不用管。

```python
def hello_ping() -> dict:
    return {"ok": True, "pong": 1700000000.0}


def register(api):
    api.register_tool("hello_ping", hello_ping, desc="示例工具：回一个 pong")
```

`api` 就三个方法，加上两个属性：

- `api.register_tool(name, fn, desc="")`：注册工具。`fn(**args)` 返回 dict，名字全局唯一。
- `api.register_router(router)`：挂一个 `fastapi.APIRouter`。
- `api.register_hook(event, fn)`：挂钩子。`fn(payload: dict)`，事件名自己定，`registry().emit(event, payload)` 触发。
- `api.dir`：你自己这个模块目录的 `pathlib.Path`。
- `api.log`：一个 logger，别自己再配。

事件名不预设。内核在合适的位置 `emit`，你只管挂。想跟另一个模块约事件名，自己约。

## 改完代码怎么生效

面板点「重新加载」会重新 import，改完代码立刻生效，不用重启内核。

- 模块内部可以相对导入：`from .helper import x`。重新加载时整个包会从内存里摘掉重来，不会拿到旧对象。
- `register(api)` 只在加载时调一次。
- 模块顶层代码在 import 时执行。**别在顶层读大文件、别联网、别起线程。** 要后台任务自己起，然后在 README 里写清楚。
- 路由自带前缀，用 `/v1/modules/<id>/…`。不带前缀也能跑，但会和别人撞。
- 工具名先到先得。撞名的话，后加载的那个模块整体加载失败，面板会写清楚是被谁占了。
- 注册到一半炸了会回滚，不会留半截工具在那儿。

## 停用和卸载

**停用**：面板「模块」页关掉开关。工具和路由当场下架，文件一个都不动。再打开立刻回来。

开关记在 `module_enabled:<id>` 里，值是 `1` 或 `0`。**空着就当启用**，所以模块装进来就能用，不用先去点开。

**卸载**：关开关（可选，但能让工具立刻下架）→ 删掉 `modules/<id>/` 整个目录 → 点「重新加载」。

残留的开关不影响运行。同一个 id 再装回来，会沿用上次的开关状态。想回到"装进来就启用"，把 `module_enabled:<id>` 这个键删掉再重载。

## 装之前先想清楚

模块代码跑在内核进程里，权限和内核一样：能读任意文件、发网络请求、直接写数据库、改 `sys.modules`。

所以：

- 只装你看得懂、信得过的。来路不明的压缩包，等于把整台机器交出去。
- `requires` 只校验，绝不替你 `pip install`。装包本身就是执行别人的安装代码。
- 模块改不了内核。它只能通过 `register(api)` 挂工具、路由、钩子。
- 出事就停用，再删目录。不用重启，也不用改代码。

## 出错了看哪儿

- **面板里根本看不到模块**：压缩包多套了一层。把内层目录提出来，让 `modules/<id>/manifest.json` 直接存在。
- **`id 与目录名不一致`**：文件夹叫 `Hello-1`，manifest 里写 `hello`。改成一样，只许小写字母、数字、连字符。
- **`缺依赖：xxx`**：`requires` 里声明的包没装。自己 `pip install xxx`。
- **`entry 文件不存在`**：entry 路径写错，或者只传了 manifest 没传代码。对照目录里的实际文件名。
- **`entry 不许往上跳`**：entry 用了 `../`。只能指模块目录里的文件。
- **`语法错误 xxx.py:12`**：代码本身写错了。按行号改，改完点重新加载。
- **入口忘了写 `register`。** 面板报 ``entry 里没有 `def register(api)`，模块不会自己挂东西``。
- **撞名。** 面板报 ``工具 `dup_tool` 已被模块 `aaa` 注册（先到先得），本模块加载中止``。改名，或者先停用占位的那个再重载。
- **路由 404**：没注册 router，或者 `kind` 不是 route/mixed，或者模块已停用。看面板的 `routes` 列表和路径前缀。
- **启动变慢**：模块顶层在干重活。挪进工具函数里，别放 import 期。
- **停用了工具还能用**：只改了开关没重载。走面板开关（它会自动重载），或者 `POST /v1/console/modules/reload`。

## 命令行和接口

```powershell
python -m app.core.modules --init   # 建 modules/ + README.md
python -m app.core.modules --list   # 打印模块清单（JSON）
```

面板用的三个接口，前缀 `/v1/console`：

```
GET  /v1/console/modules
POST /v1/console/modules/{module_id}/toggle   body {"enabled": true|false}
POST /v1/console/modules/reload
```

鉴权和 `console.py` 同口径：`console.token` 配了，就要带 `X-Console-Token` 或者 `?token=`。

每个模块的返回里都有 `error`（人话）、`warnings`、`loaded`、`tools`、`routes`、`hooks`。排错先看 `error`。

## 给改内核的人

`main.py` 只要两行，放在别的 `include_router` 之后、面板 `app.mount("/", …)` 之前：

```python
from app.core import modules as modules_mod
modules_mod.attach(app)
```

为什么不是 `include_router`：模块路由要运行时才知道有哪些，必须由 `attach` 在面板 Mount 之前插进去。它顺便把启动时的加载也做了。

路由一定得插在 `Mount("/")` 前面。Starlette 按顺序匹配，挂在面板静态目录后面的路由永远收不到请求。
