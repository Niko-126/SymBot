# 06 · 记忆（业务层）

> 本文只讲**用起来是什么样**，不讲引擎实现。引擎属闭源资产，边界见 [docs/07](07-vendor-memory.md)。

## 1. 她在记什么

- **事件**：你们聊过的事（谁、什么时候、说了什么）
- **事实**：关于你/关于她的稳定信息（名字、习惯、重要日期）
- **偏好**：你喜欢什么、讨厌什么
- **念头**：她自己冒出来的想法
- **原话**：她说话的风格样本（用来维持语气一致）

## 2. 记忆怎么用

1. 一句话进来 → 先落事件（原文，用于复盘）
2. 需要长期保留的 → 提炼成记忆条目，按人、按场合分区
3. 下一轮对话 → 按线索找回相关的几条，压成一段进上下文
4. 常用的热度回升，久不用的慢慢变淡；重要的可以钉住

## 3. 面板里能做什么

- 看某个人的记忆（按人过滤、按类型筛）
- 钉住 / 删除单条
- 清空某个人的记忆（不可撤销）
- 看记忆条数、类型分布

## 4. 边界

- 记忆按用户与场合隔离：群里 A 的记忆不会串到 B
- 家人（生父/干爹）走独立分区
- 数据在本地 SQLite，**备份方式见 [docs/36](36-记忆系统说明.md)**
- 本文不涉及打分公式、权重、表结构等实现细节
