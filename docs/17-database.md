# 17 · 数据与存储（概览）

> 只讲"数据在哪、怎么备份"，不展开表结构细节。

## 1. 存储形态

- 单文件 **SQLite**（WAL 模式）：`data/life.db`
- 配套：`life.db-wal`、`life.db-shm`（运行中必须一起拷）
- 其他：`data/stickers/`、`data/voices/`、`data/covers/`、日志

## 2. 数据分几块

| 块 | 大概装什么 |
|---|---|
| 用户与关系 | 好友/群成员、四维数值、阶段、恋人 |
| 对话 | 消息原文、来源、场合 |
| 记忆 | 由闭源引擎管理，业务层只经统一入口读写 |
| 日程与生活 | 作息、日记、念头、主动开口记录 |
| 运行时 | kv 开关、缓存、额度 |

> 具体表名/列名不在此展开；需要排查问题时看 `sqlite_master` 即可，属本地数据。

## 3. 备份与迁移

关掉程序 → 整个 `data/` 拷走；新机器装好程序 → 把 `data/` 放回去 → 启动。
运行中直接拷 `life.db` 可能拿到旧快照，务必连 `-wal`、`-shm` 一起。
