# 人设怎么改

Σ 镜衡万象 · Symvolve

> 人设卡是她的底稿：性格、说话方式、怎么叫你、哪些话不能碰。
> 这篇讲面板上每一项管什么、怎么改、改坏了怎么退回去。
> 想让她「像另一个人」的人，看这篇。

## 人设卡是什么

一张卡，决定她是谁。

- 名字、物种、年龄、一句话介绍。
- 她住在哪、长什么样。
- 八个性格维度各自的强弱。
- 说话的风格和硬规矩。
- 每个阶段怎么称呼你。
- 底线和禁区。

它不决定这些：记忆、关系走到哪一步、家人名单。
改人设不会清空记忆，也不会让你们的关系归零。

默认那张卡是 `persona/` 目录里的 `whale-chan.yaml`。
面板「人设卡」页是它的可视化版本。你改面板，等于改这张卡。

## 面板上能改什么

打开面板 → 人设卡。左边六块，右边是预览。

| 块 | 里面有什么 | 管什么 |
|---|---|---|
| 基本 | 名字、物种、年龄、自称、一句话 | 她怎么介绍自己 |
| 人设正文 | 世界 / 经历、形貌 | 聊到自己的来历时，拿什么当背景 |
| 性格特质 | 八个维度，可拖动 | 遇到事时的反应强度 |
| 说话风格 | 风格、规则 | 句子长短、一次发几条、什么语气 |
| 阶段表 | 阶段名、走到哪算进这一档、她怎么称呼你 | 关系走到哪，她怎么叫你 |
| 边界词 | 原则、底线、修复、禁止 | 能做什么、绝对不做什么 |

**八维性格**是这八个：温柔、沉静、好奇、黏人、理性、敏感、幽默、自持。
每一维都有上下限。你拖过头，保存时会被拉回范围内。
这是防止一格拉满，人就变扁了。

**说话风格**分两栏。
风格是「她大概什么样」，一行一条。
规则是硬约束，比如「一次只说一句」「不用感叹号」。

**阶段表**里，你能改阶段名、进档的位置、称呼。
behavior 和 unlock 两列在这一页不显示，保存时原样保留。想改那两列，去改 YAML。

**边界词**里，禁止那一栏最重要。
一行一条，写具体行为，别写抽象词。

## 改完立刻生效

点右上角「保存」。

1. 面板把改动写进 `data/persona-active.yaml`。
2. 旧的 active 先备份到 `data/persona-backup/`。
3. 她重新读一遍人设。

不用重启，不用重开面板。
下一句话就是新的。
改称呼最明显：保存完发一句，她的叫法就变了。

## 几个实用改法

### 让她话少一点

改哪：说话风格 → 规则。

```text
一次只说一句
每条不超过十五个字
不主动追问，不连发
```

顺手把风格里「连发两三条是常态」那条删掉。
只改规则、不改风格，她还是会想多说，只是被摁住了，读起来别扭。

### 换个称呼

改哪：阶段表 → 她怎么称呼你。

- 想每个阶段都叫「老板」：每一行的称呼都写「老板」。
- 想阶段递进：观察者叫「你」，熟一点叫名字，再往后叫只有你们俩知道的称呼。

注意：「他的名字」「小名」「你定的称呼」这种是占位说明词，别当成真称呼照抄。
想让她真这么叫，就写死具体的那几个字。

右边预览会显示「她现在会怎么称呼你」。
改完先看预览，再保存。

### 加一条禁区

改哪：边界词 → 禁止（一行一条）。

写具体行为，别写「对她好一点」这种。

```text
不要叫我主人
不要提我的工作
不要用沉默惩罚我
```

保存之后，这几条进她的硬约束。
她可以绕开话题，但不能顶着来。

### 让她别那么黏

改哪：性格特质 → 黏人。
往下拖一点，别拖到底。拖到底，她对你就没热乎气了。
同一块里的「温柔」「幽默」也可以微调。
一次只动一两维，好判断是哪一维起了作用。

## 导入导出

右上角两个按钮：导出 JSON、导入 JSON。

- **导出**：把当前人设存成一个 JSON 文件。只含人设的内容，不含家人名单、关系、记忆。
- **导入**：选一个之前导出的 JSON，校验通过就写进去，同样先备份再生效。

换机器这么办：

1. 老机器：人设卡 → 导出 JSON。
2. 把 JSON 拷到新机器。
3. 新机器：人设卡 → 导入 JSON。
4. 发一句话，试试称呼对不对。

导入会检查两样：有没有名字，阶段表是不是空的。
缺了会被拒绝，原文件不动。
性格数值超范围，会被拉回范围内，不会报错。

## 改坏了怎么回滚

每次保存或导入，旧版本都会先备份。

位置：`data/persona-backup/`。
文件名是 `persona-active-` 后面跟年月日时分秒，中间用短横线隔开。
同一天存多次，后面会加序号。
第一次保存时还没有旧文件，就没有这一步。从第二次起才会有备份。

回滚步骤：

1. 完全退出程序。
2. 进 `data/persona-backup/`，挑一个时间对得上的文件。
3. 复制出来，改名成 `persona-active.yaml`，放回 `data/`，覆盖现在这份。
4. 重新打开程序。

嫌麻烦，就用导出过的 JSON 重新导入一次，效果一样。

保存失败的时候，面板会给红字提示，旧文件不会被写坏。
看到红字先别关页面，把提示读完。

## 人设和家人名单是两回事

这两样经常被搞混。

| | 人设卡 | 家人名单 |
|---|---|---|
| 在哪改 | 面板「人设卡」 | 面板「设置 → 账号 → 家人」 |
| 管什么 | 她是谁、怎么说话 | 谁是家里人、怎么称呼 |
| 改了会怎样 | 说话方式立刻变 | 恋爱线和通知对象变 |

改人设，不会把家人改没。
删家人，也不会改她的性格。
家人永远不进恋爱线，这条不受人设影响。
