# 03 · 目录与文件（概览）

> 只列目录职责，不再逐个文件列行数。

| 目录 | 职责 |
|---|---|
| `app/` | 内核：API、对话主链、记忆门面、关系、生活、语音、工具、适配器 |
| `app/memory/` | 记忆业务门面 + 闭源引擎接口层（容器与解封器） |
| `panel/` | 纯静态面板（对话/控制台/设置/人设卡/热梗） |
| `persona/` | 人格 YAML 与备份 |
| `modules/` | 外置模块（`manifest.json` + 入口） |
| `scripts/` | 启动器、测试、打包、签名、水印 |
| `docs/` | 文档（本目录） |
| `desktop/` | Electron 桌面壳与打包配置 |
| `data/` | 运行时数据（不入库） |

> 逐文件清单与行数不再公开；需要定位代码用 `git ls-files` 或编辑器搜索。
