# 人设备份

> 这篇讲 `persona/backup/` 里放的是什么、谁写的、什么时候该回滚。
> 改了人设心里没底的，先看这篇，能省一次事故。

## 里面是什么

放人设文件的旧版本。每份都是某个时间点的原样拷贝，文件名带日期和序号，一眼能看出先后。

现在有两份：一份是原版，一份是改到一半的旧稿。它们只用来对照和回滚，程序不会加载。

## 谁写的

作者手写的。改人设之前，先把当前文件复制一份进来，改成带日期的名字，再动原文件。

规矩只有一条：备份只进不出。要改就改新文件，别拿去改备份。

## 怎么回滚

1. 先停掉程序。跑着的时候换人设，容易换来一份半截的。
2. 进这个目录，挑一个日期对的。
3. 复制出来，改回正式人设的文件名。
4. 覆盖正式文件。
5. 启动，翻到人设卡那页，看有没有报错。
6. 确认没问题，再接着聊。

回滚之前，先把眼下这版也备份一份。不然回错了，前后都没了。

## 别做的事

- 别删备份。删了就既没得对照，也回不去。
- 别在备份上直接改。改完就分不清哪份是原始的了。
- 别把备份改名顶上去当正式人设。程序只认正式文件名。
