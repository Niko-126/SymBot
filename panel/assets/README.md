# 面板静态资源

> 这篇清单 `panel/assets/` 里有哪些图、各用在哪、放多大合适。
> 改面板或者换 logo 之前看一眼，别把图换裂了。

## 这里放什么

只放面板要用的静态图：logo、图标、以后可能加的插画。

不放截图，不放素材库，不放表情包。表情包归 `data/stickers/`，两回事。

## logo 清单

| 文件 | 用在哪 | 建议尺寸 |
|---|---|---|
| `whale-logo-64.png` | 顶栏、设置页小标 | 64×64 |
| `whale-logo-128.png` | 列表、卡片这类中间尺寸 | 128×128 |
| `whale-logo-256.png` | 空状态大头像，也是桌面图标的源图 | 256×256 |
| `whale-logo.ico` | 浏览器标签、快捷方式 | 含 16 到 256 多档 |
| `whale-logo-desktop.ico` | 桌面快捷方式 | 含 16 到 256 多档 |

## 尺寸约定

- 页面里显示多大，就挑最接近的那一档。别拿 256 硬缩到 26 像素。
- 只缩不放。放大一定糊。
- 换图保持正方形、透明底，四周留一点空。
- 新增尺寸先想清楚用在哪，别一口气塞五档进去。

## 换 logo 的步骤

1. 备一张正方形、透明底的源图，边长不低于 256。
2. 按上表导出 64、128、256 三档 png，文件名别改。
3. 用源图转两份 ico，都要含 16 到 256 多档。
4. 桌面壳那层的图标也一起换，别只换面板。
5. 刷新页面，顶栏、空状态、设置页三处挨个看。

换完没生效，先强刷一次，浏览器会缓存图片。
