# 模块目录

> 这篇讲 `modules/` 是干什么的、现在里面有什么、怎么自己加一个。
> 想给 SymBot 加功能又不想动内核的，看这篇。

## 这是什么

`modules/` 放外置模块。一个模块一个目录，扔进去、点重新加载，就生效。不用改内核代码，也不用重新打包。

打个比方：内核是插座，模块是插头。插上就有电，拔下来就没，插座本身不动。

## 现在只有 hello

目录里只有一个 `hello/`，是示例，别删。它干两件事：注册一个叫 `hello_ping` 的工具，挂一条 `/v1/modules/hello/ping` 路由。加起来不到三十行，照着抄最快。

除它以外，仓库不带任何模块，也没有官方市场，别去找。

## 怎么加一个

1. 建目录：`modules/你的id/`，目录名必须和清单里的 id 一模一样。
2. 写清单 `manifest.json`：id、name、version、entry、kind、requires，六个字段都别漏。
3. 写入口文件：里面必须有一个 `register(api)` 函数，工具、路由、钩子都从这里挂上去。
4. 生效：面板点「重新加载」，或者把内核重启一遍。

放错了不会崩。面板的模块页会直说哪儿不对，先看那一行提示再改。

## 两句提醒

- 模块跑在内核进程里，权限和内核一样。只装你自己看得懂的东西。
- 停用就是删目录。删完它的工具和路由立刻下架，不留尾巴。

内核只在这份文件不存在的时候，才会补一份默认稿。你手改的内容不会被覆盖。
